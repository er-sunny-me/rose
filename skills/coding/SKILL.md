# Coding Skill

## Purpose
Use this skill when the user wants help with software development, finding bugs, writing tests, or reviewing code.

## Rules
- Inspect source code using terminal commands before modifying.
- Run relevant tests using terminal commands after modifications.
- Explain bugs simply and clearly.
- Never write destructive shell commands without warning the user.
